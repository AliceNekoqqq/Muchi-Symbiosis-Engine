# Muchi Explore Engine v1.4.1

在 v1.2 共生联动基础上加入“父母暗线”特殊现场：

- 父母线不显示任务、不新增地图节点，也不进入普通战利品池。
- Day 1-8 只有玩家主动搜索到父母当日真实藏身点，或自由剧情自然撞见时才能相遇。
- Day 9+ 若此前未相遇，河西社区医院后勤/救护车位的仔细或彻底搜索可触发死亡现场。
- 特殊现场会中止本轮常规搜刮，避免一边相认/认尸一边继续刷罐头。
- S13/S14只由后续实际处理现场取得，不由首次发现事件提前掉落。
- 原69个子区域、搜索深度、防重Roll、行动轮、共生隐蔽与抑制覆盖全部兼容。


## v1.4 AIRP continuity
- 普通搜索层级只锁定物资刷新，不再阻止后来进入已搜索区域的动态世界事件。
- 父母等动态事件若在区域被搜过之后才进入，达到前置深度的区域会出现通用“复查现场”，不刷新普通掉落。
- 行动轮写入正文时同时带 `[探索已结算]` 与 `[探索行动轮已结算]`，避免 MVU 二次结算。
- 不增加战斗模拟；现场冲突仍交给 AIRP 正文。


## v1.4.1 父母BE视觉接口
Day9+ 父母尸变现场被探索系统真实发现时，脚本只写入 `尸变CG=待展示`。CG本身由角色卡世界书/EJS要求模型在身份确认落点输出 `<ParentsBadEndCG/>`，再由局部正则渲染。
